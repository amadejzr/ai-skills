- CLI reviewers (docs only, not run):
  - claude: `git diff main... | claude --bare -p "<prompt>" --output-format json --json-schema '<schema>' --allowedTools "Read,Grep,Glob"` -> `.structured_output`.
  - codex: `codex exec -s read-only -m <model> --ephemeral --output-schema review.schema.json -o out.json "<prompt>"`; `codex review --base <branch>` has no schema output.

  - gemini: `gemini -p "<prompt>" --output-format json -m <model>` -> `.response`.
  - openai/codex-plugin-cc ships `/codex:review --base main` and `/codex:adversarial-review`.
